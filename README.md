### How to Test the Model

1. Open the [Live Demo](https://ensemble-credit-card-fraud-detectio.vercel.app/).
2. Download [`sample_transactions.csv`] from this repository.
3. Upload the CSV file through the application.
4. Run the prediction to view the fraud detection results.

**Note:** Use the provided sample dataset to test the application. Ensure the uploaded file follows the expected CSV format.
